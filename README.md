# ICT2215 Nature Frame

学生：Li Haoran · I24028229

这是只用 HTML5 和 CSS3 的单页基础网页项目。无需 JavaScript、Node.js、插件、网络或服务器。

## 打开和预览
1. 在 VS Code 中选择“文件 → 打开文件夹”，打开 ICT2215_Nature_Frame。
2. 在文件管理器中双击 index.html，用 Chrome、Edge 或 Firefox 打开。不要只打开网页而漏掉 assets 文件夹。
3. 修改 index.html 或 style.css 后按 Ctrl + S，在浏览器按 Ctrl + R；样式未更新时按 Ctrl + Shift + R。
4. 点击 Home / About / Services / Contact 检查跳转。视频按播放键播放，Submit 仅用于展示，不发送或保存数据。

## 文件入口
- index.html：英文网页内容，每一行均有中文解释。
- style.css：页面样式，每一行均有中文解释；搜索【修改】可定位操作。
- assets/images/：四张原图，保持原始内容和比例。
- assets/video/nature.mp4：你提供的 207824442.mp4，约 29 秒，本地播放。
- design/wireframe.png、design/design-plan.md：线框图、配色、字体和 CRAP 理由。
- documentation/report.docx：可编辑英文 Word 初稿，已嵌入截图；report.md 为同内容 Markdown 源稿。
- documentation/现场修改指南.md、中文代码解释.md、英文演讲稿.md：课堂准备材料。
- documentation/questionnaire.md、testing-results.csv、improvements-template.md：真实测试与改进模板。
- documentation/screenshots/：真实浏览器页面截图，以及由实际保存代码生成的代码截图。
- documentation/检查记录.md：实际技术检查结果和边界。
